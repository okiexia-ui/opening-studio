# Opening Studio v0.3.0

为 ChatGPT、Claude 和其他 macOS 应用提供八种开屏。每个应用可以独立选择样式和开关。默认问候是 **Welcome Tommy**。

- **雾彩 · 连笔**用彩色笔迹写出问候，延伸到 OpenAI 六瓣结，再从结心进入 ChatGPT 窗口。
- **朱砂 · 启卷、霁蓝 · 引力、曜金 · 剧场**提供纸页、轨道和舞台三种构图。
- **长城 · 通行、星烛 · 咒语、星际 · 远航、霓虹 · 雨夜**加入朱印落款、烛光书写、行星晨昏线和霓虹倒影。
- Claude 默认使用朱砂主题与星芒标志。其他普通桌面应用可通过“添加应用”选取，开屏使用本机应用图标。
- 只有新启动的应用在前台出现可见窗口时才播放。窗口关闭或切到其他应用时立即收起，再切回来保持安静。
- 可编辑问候语、名字、政务标题和印章。设置同步期间可以继续输入。写入失败会保留上次保存的配置。
- 安装器在替换前验证新包。登录项启动失败时恢复旧版，升级时保留原来的停用状态。

## 下载

| 附件 | 内容 |
| --- | --- |
| `OpeningStudio-v0.3.0-macos-universal.zip` | macOS 13 及以上的 Apple Silicon / Intel 通用应用和安装器 |
| `OpeningStudio-v0.3.0-demos.zip` | 八种样式及一个 Claude 示例，共九段 1920×1080、60 fps 的 H.264 MP4 |
| `OpeningStudio-v0.3.0-source.zip` | 源码、字体及授权文件、测试和构建脚本 |
| `SHA256SUMS.txt`、`manifest.json` | ZIP 校验值和文件清单 |

解压通用安装包，双击 `安装 Opening Studio.command`，从菜单栏的 **应用与开屏…** 选择应用和样式。此构建使用 ad-hoc 签名，尚未取得 Apple 公证。仓库公开源码，Release 保留为草稿。

在 Apple Silicon 实机上，Claude 完整播放了 11.8 秒朱砂开屏，再次打开同一进程没有重播。渲染回归覆盖八种主题、三类标志和五种窗口比例。
