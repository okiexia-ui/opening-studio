# Opening Studio v0.3.0

为 ChatGPT、Claude 和其他 macOS 应用提供八种开屏，每一种都可以定制。每个应用独立选择样式和开关；默认问候是 **Welcome Tommy**，可以改成你自己的名字。

- **雾彩 · 连笔**：彩色笔迹一笔写出问候，延伸到 OpenAI 六瓣结，再从结心进入 ChatGPT 窗口。
- **水墨 · 山水、极光 · 冰原、磷光 · 终端**：墨滴晕开成山、毛笔按笔锋写名并钤印；冰原上的极光光幕；旧显像管开机、光标敲字、示波器描出标志。
- **长城 · 通行、星烛 · 咒语、星际 · 远航、霓虹 · 雨夜**：朱印落款、烛光书写、行星晨昏线和霓虹倒影。
- **每种样式都能定制**：多套配色或自选主色、节奏（舒缓 / 标准 / 利落）、字体、一行或两行排版、字号，以及各自的场景元素，边改边预览。
- **问候可编辑**：问候语、名字、政务标题和印章。一笔写出的样式会按文字当场生成单线笔迹，中文名字也可以。
- Claude 默认使用水墨样式与星芒标志。其他普通桌面应用可通过“添加应用”选取，开屏使用本机应用图标。
- 只有新启动的应用在前台出现可见窗口时才播放。窗口关闭或切到其他应用时立即收起，再切回来保持安静。
- 设置同步期间可以继续输入。写入失败会保留上次保存的配置。
- 安装器在替换前验证新包。登录项启动失败时恢复旧版，升级时保留原来的停用状态。
- 测试版中的朱砂 · 启卷、霁蓝 · 引力、曜金 · 剧场已由水墨、极光、终端取代，原来的选择会自动换成对应的新样式，设置文件不被改写。

## 下载

| 附件 | 内容 |
| --- | --- |
| `OpeningStudio-v0.3.0-macos-universal.zip` | macOS 13 及以上的 Apple Silicon / Intel 通用应用和安装器 |
| `OpeningStudio-v0.3.0-demos.zip` | 八种样式及一个 Claude 示例，共九段 1920×1080、60 fps 的 H.264 MP4（默认选项） |
| `OpeningStudio-v0.3.0-source.zip` | 源码、字体及授权文件、测试和构建脚本 |
| `SHA256SUMS.txt`、`manifest.json` | ZIP 校验值和文件清单 |

解压通用安装包，双击 `安装 Opening Studio.command`，从菜单栏的 **应用与开屏…** 选择应用、样式和定制选项。此构建使用 ad-hoc 签名，尚未取得 Apple 公证，首次打开的步骤见 README。

在 Apple Silicon 实机上，Claude 完整播放了 11.8 秒的开屏（当时为朱砂样式），再次打开同一进程没有重播；重新设计后的版本已在同一台 Mac 上安装运行。渲染回归覆盖八种样式、三类标志、五种窗口比例和每种样式的全部定制选项（119 种组合）。
