# Welcome Tommy

Personal macOS ChatGPT cold-launch introduction. A single travelling pen draws
`Welcome Tommy`, continues into the OpenAI Blossom on the right, then takes the
viewer through its centre into the real application window.

- Master: 1920 × 1080, 60 fps, 15.8 seconds, silent UI animation.
- 0.0–0.6: the first small curved stroke arrives; no title or loading label.
- 0.6–8.1: rounded connected handwritten letters, centred as one phrase.
- 8.1–9.3: the same tip exits the y descender and sweeps to x = 1392, y = 540.
- 9.3–13.1: trace the sourced Blossom contours; the greeting fades progressively.
- 13.1–13.5: brief recognition beat, with the travelling tip still in motion.
- 13.5–15.8: accelerate through the centre of the mark; open an aperture onto
  the actual app. The MP4 uses a matching pale end field since it cannot contain
  the user's future live app window.
- Frosted ground: #edf0f6 with broad pastel fields. Line width 9–12 px for letters,
  4–6 px for the logo. Broad diffuse colour spill, no specular/glass bevel.
- Palette: coral, rose, lavender, cornflower, cyan, mint, warm gold.
- Letter height: 175 px capitals/ascenders, 95 px x-height. No font outline reveal.
- Continuous path and continuous position at every phase boundary; no cuts.
- The native overlay uses the same renderer at arbitrary window sizes, with
  NSVisualEffectView behind it, and a native even-odd aperture mask at the exit.

BANNED: liquid-glass refraction, glossy extruded letters, multiple detached pen
tips, speed typing, bouncy motion, fake ChatGPT screenshots, decorative text,
full-screen playback unrelated to the target window, replay on app activation.

Reference: Apple's installed Macintosh 3D hello curves were inspected for the
loop shapes, not copied into the custom lettering. Exact iOS 18 playback timing
is not available as a verified reference; the 7.5-second phrase is an authored,
deliberately unhurried approximation.
